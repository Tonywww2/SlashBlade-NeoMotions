# 大剑与双刀出招表 · 0.4.4

适用于两把试作型，以及用手册切换到对应动作树的拔刀剑。L＝攻击键，R＝使用键，潜行默认 Shift，前／后默认 W／S。按键改绑后使用对应功能键。20 tick＝1 秒，所有时间从当前招式开始计算。

动画与时序来自本地解包的 Wilds：大剑 wp00、双刀 wp02。表中的 MOT 编号可在 `motions/source_actions.json` 查到原路径、哈希、原始帧、命中窗口和转换规则。键位、简化连段、SA 与伤害倍率是本模组适配，不代表原作完整操作表或全部模式。

0.4.3 起，当前招式、阶段、进度以及蓄力／SA 文字提示统一受客户端配置控制，默认关闭。在游戏实例 `config/slashblade_neomotions-client.toml` 的 `[hud]` 节将 `showMoveInfo` 改为 `true` 可开启。此开关不改变招式规则、音效或粒子。

0.4.4 起，两本剑术手册的 Tooltip 也提供精简的“输入／招式／后续”表格。名称读取本机原作猎人笔记的 MSG.23，来源及 GUID 见 [move-name-sources.json](move-name-sources.json)。

## 大剑

| 输入／时机 | 招式 | 后续衔接 |
| --- | --- | --- |
| 地面待机 L | 直斩 | L → 横扫斩；R → 第二段蓄力 |
| 连续 L，按各段窗口输入 | 直斩 → 横扫斩 → 上捞斩 | 再 L 回到直斩 |
| 地面按住 R，再松开 | 第一段蓄力 → 蓄力斩 | 后摇按住 R → 第二段蓄力 |
| 蓄力斩后接 R，蓄力后松开 | 第二段蓄力 → 强蓄力斩 | R → 第三段蓄力；L → 强力横扫斩 |
| 强蓄力斩／强力横扫斩后接 R，再松开 | 第三段蓄力 → 真·蓄力斩 | 第一击 → 全身翻转 → 第二击；之后 R → 第一段蓄力 |
| 蓄力中重新轻按潜行 | 对应段的冲撞攻击 | 保持 R → 下一段蓄力，最高第三段；L → 飞身跃入横扫斩 |
| 待机时潜行＋L | 横扫斩 | 松开潜行后 L → 上捞斩 |
| 待机时潜行＋后退＋L | 上捞斩 | 松开潜行后 L → 直斩 |
| 空中 L 或 R 起手 | 跳跃蓄力斩 | 着地自动接跳跃蓄力斩（落地）；地面 L → 横扫斩 |
| 任意段蓄力中轻点 L，保持 R，随后松 R | SA 预备 → 当前刀的 SA | 技能结束后回到本动作树 |

蓄力斩后可以提前按住 R；衔接窗口打开后才开始下一段蓄力计时。窗口前松开会撤销预输入。L 也可在源事件的预输入窗口内排队，例如直斩／蓄力斩从第 11 tick 接收横扫斩输入，第 16 tick 执行；强蓄力斩从 18 tick 接收强力横扫斩，20 tick 执行。没有对应源预输入字段的分支需要等到衔接窗口。持续按住潜行不会重复冲撞攻击，需松开后再按，且本段至少已蓄力 2 tick。

### 蓄力等级

“第一／二／三段”决定释放哪一种蓄力斩；每段独立计算蓄力等级。阈值取自 USER `_ChargeParam`（强蓄力与真·蓄力的对应参数相同）。倍率为本模组平衡值。

| 持有时间 | 等级／结果 | 该段基础倍率乘数 |
| --- | --- | --- |
| 0–15 tick | Lv.0，未蓄满一级 | ×1.00 |
| 16–30 tick | Lv.1 | ×1.15 |
| 31–45 tick | Lv.2 | ×1.35 |
| 46–59 tick | Lv.3 | ×1.75 |
| 60 tick | 过蓄降至 Lv.2，自动出刀 | ×1.35 |

SA 预备继承本段已经蓄力的时间，使用本体蓄满门槛、精准窗口、附魔条件和消耗。未蓄满松 R 会取消；累计到 60 tick 也取消，不自动消耗耀魂。冲撞攻击会清除 SA 预备。

### 大剑时序

“衔接”按目标分支列出；“长度”是完整原作片段转换后的长度，允许在窗口内提前接招。源连续碰撞窗口被适配为窗口内的单次命中脉冲。刀光平面与方向由对应刀刃轨迹生成，蓄力斩为向下直斩。

| 上捞斩 | 215 | 24 | 第一段蓄力／横扫斩 34；直斩 36 | 94 | 1.25 |

冲撞攻击前 14 tick（原始霸体结束帧 40 向上量化）拥有抗击退，承受伤害乘以 0.3。没有实现原作精准冲撞攻击分支。地面动作按原始根轨迹推进，经过 Minecraft 碰撞处理；动画中的起跳不等同于实体获得腾空判定。

## 双刀（右手刀身＋左手刀鞘）

左手的第二把武器使用当前模型的刀鞘，不需要副手放第二件物品。招式名称按原作简中猎人笔记：二连斩、二连回斩、车轮斩、鬼人连斩Ⅰ、鬼人六连斩、挥斩、上捞斩、跳跃二连斩。鬼人招式在本模组的简化连段中直接使用。

| 输入／时机 | 招式 | 后续衔接 |
| --- | --- | --- |
| 地面 L | 二连斩 | L → 二连回斩 |
| 继续 L | 二连回斩 → 车轮斩 → 鬼人连斩Ⅰ → 鬼人六连斩 | 再 L 回到二连斩 |
| 潜行＋L | 回旋斩 | 松开潜行后 L → 鬼人连斩Ⅰ |
| 潜行＋前进＋L | 挥斩 | 松开潜行后 L → 车轮斩 |
| 潜行＋后退＋L | 上捞斩 | 松开潜行后 L → 二连斩 |
| 空中 L 或 R 起手 | 跳跃二连斩 | 着地自动接落地收势；之后 L → 车轮斩 |
| 地面长按 R，随后松开 | SA 架势 → 当前刀的 SA | 不需要先点 L |

上捞斩使用原作片段 259，其根轨迹略微向前；S 是分支选择键，并不把原动作改成向后滑步。前后同时输入时，上挑分支优先。双刀按衔接窗口再次输入，没有大剑式的按住 R 自动续蓄。这里的五段循环是选定原作片段组成的 Minecraft 连段，未实现完整鬼人／鬼人强化状态。

落地片段没有源碰撞事件，已删除旧版额外的落地鞘斩伤害。地面移动使用各招式自身根轨迹，不再用统一突进／后撤冲量。没有额外无敌或减伤。

双刀 SA 使用本体门槛、精准窗口与消耗；未蓄满松开、离地、换刀、断刀、封印或累计持有到 54 tick 会取消。两把试作型初始 SA 分别是大剑的纵向剑气、双刀的回旋斩。释放后的技能动作和效果由本体提供；本体 V 键特殊动作、中键幻影剑保留。

## 动作来源与适配边界

腿部取自与上身相同的 MOT 姿态，保留重心移动与翻身；Minecraft 无膝关节，采用大腿到脚的方向转换为刚性腿。状态切换使用 MCT 过渡帧数混合根骨与腿，待机放行原版走路，空中末姿等待服务端落地。大剑背鞘跟随躯干，双刀鞘跟随左手。

已提取的是动作、碰撞／取消／预输入事件、蓄力参数和连接参数。BTable 的完整表体已编译到游戏程序，当前没有导入完整程序状态机。选招键位、缺少对应源分支时的默认衔接、伤害平衡、SA 和实体移动限幅都属于适配。详细来源及重建命令见 [动画管线](ANIMATIONS.md)，检查范围见 [验证记录](VALIDATION.md)。
